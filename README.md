# Cafe Aramesh Backend

A clean FastAPI and PostgreSQL backend foundation for the Cafe Aramesh smart menu.

## Status

Phase 1: backend foundation and database setup.

## Planned stack

- Python 3.11+
- FastAPI
- PostgreSQL
- SQLAlchemy 2
- Alembic
- Pydantic Settings
- Pytest and HTTPX

## Development

See `.env.example` and the setup instructions added as the foundation is implemented. Never commit `.env` files, passwords, API keys, or other secrets.
